# Shabari Girisha G S – Portfolio Website

A modern single-page portfolio website showcasing experience in Business Analytics, Business Intelligence, Blockchain/Web3, and Entrepreneurship.

## Tech Stack

- HTML5
- CSS3 (mobile-first, responsive)
- Vanilla JavaScript

## Quick Start

1. Open `index.html` in a web browser, or
2. Use a local server:

   **Python 3:**
   ```bash
   python -m http.server 8000
   ```
   Then visit http://localhost:8000

   **Node.js (npx):**
   ```bash
   npx serve
   ```

## Features

- Responsive, mobile-first layout
- Sticky navigation with mobile menu toggle
- Smooth scrolling between sections
- Active section highlighting
- Dark theme optimized for readability
- Semantic HTML and basic accessibility (ARIA, keyboard support)

## Sections

- Hero
- About
- Domain Focus (BI, Fintech, Blockchain, Entrepreneurship)
- Experience (Web3 Developer, Alpha Roofings, Bosch)
- Education (SUNY Buffalo, IIM Udaipur, REVA)
- Skills
- Certifications
- Projects
- Contact

## Customization

- **Profile image:** Add an image in `assets/` and reference it in the hero section.
- **Resume:** Add a PDF to the project and update the hero CTA link.
- **GitHub:** Add a GitHub link in the Contact section.
